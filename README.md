# 🧠 Brain Warrior — Quiz with GUI

Brain Warrior is a C++ quiz application designed with an interactive GUI-based quiz experience. It allows users to test their knowledge through different quiz categories with a 10-second timer for each question.

## 🎯 Features

* 🧠 Brain Warrior Quiz
* 🖥️ GUI-based quiz experience
* 🧮 Math Quiz
* 🔬 Science Quiz
* 🌍 General Knowledge Quiz
* ⏰ 10-second timer for each question
* ✅ Automatic answer checking
* 🏆 Final score display
* 👤 User name input
* 📚 10 multiple-choice questions per category

## 📚 Quiz Categories

The application provides three categories:

1. **Math**
2. **Science**
3. **General Knowledge**

## 🛠️ Technologies Used

* C++
* Object-Oriented Programming (OOP)
* Windows API
* `conio.h`

## ▶️ How to Run

Compile the `main.cpp` file using a C++ compiler on Windows:

```bash
g++ main.cpp -o brain-warrior
```

Then run:

```bash
brain-warrior.exe
```
